# Auto Suggestion System Using Trie Data Structure

## Project Overview
This project implements an Auto Suggestion System using the Trie Data Structure. The system stores words efficiently and provides instant suggestions based on user-entered prefixes.

## Features
- Trie-based word storage
- Fast prefix searching
- Auto suggestion generation
- User-friendly output
- Object-Oriented Programming (OOP) implementation

## Technologies Used
- Python 3
- Trie Data Structure
- Visual Studio Code

## Sample Input
app

## Sample Output
Suggestions:
1. app
2. apple
3. application
4. apply

- Search Engines
- Mobile Keyboards
- Dictionary Applications
- Contact Search Systems
